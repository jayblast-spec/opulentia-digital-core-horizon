# Contributing

Thanks for your interest in Opulentia Digital Core Horizon.

## Local development

```bash
npm install
npm run dev
```

## Before opening a pull request

- Run `npx tsc --noEmit` to confirm the project type-checks.
- Run `npm run build` to confirm a real production build succeeds.
- Keep changes scoped — one concern per pull request.

## Reporting issues

Open a GitHub issue with a clear description of the problem and, where
relevant, the exact steps to reproduce it.
